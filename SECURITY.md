# Security and trust boundaries

All inputs and results are public. No funds are held or transferred. Only Stable Studionet is supported. The development signer used for public evidence is disposable and not a funded account; public evidence never contains signing secrets.

Do not infer truthful declarations, complete specifications or unique humans from wallet signatures. Independent interpretation can reproduce a shared mistake. Prompt injection remains a known model risk; unsupported text must block rather than become authority. Network finality and successful agreement must both be inspected. A digest is only content integrity, not provenance.

A failed or uncertain write is not automatically retried. Keep its hash and inspect the receipt before deciding what to do. Do not fund development signers or publish keys. This repository does not implement Appeal. Reproduce normal read checks without new writes.
